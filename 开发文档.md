## 1. 第一阶段：需求分析与PRD设计

### 1.1 项目概述

#### 1.1.1 项目背景

校园物品量化管理系统（校物通）是为学校设计的一款轻量级库存管理软件，旨在解决学校物品管理的痛点：
- 物品管理混乱，缺乏统一的入库、出库、盘点流程
- 库存信息不透明，无法实时掌握物品使用情况
- 统计分析困难，无法为管理层提供决策依据
- 系统部署复杂，需要专业IT人员维护

#### 1.1.2 项目目标

**核心目标**：
- 实现学校物品的全生命周期管理（入库、出库、盘点、报废）
- 提供实时库存查询和预警功能
- 支持多维度统计分析（按物品、按科室、按时间）
- 系统轻量化，易于部署和维护

**技术目标**：
- 前端采用 Vue3 + Vite + Element Plus + Vant 4，支持 PC 和移动端
- 后端采用 FastAPI，提供高性能 restful API
- 数据库采用 SQLite，轻量化部署
- 支持 50 人以内同时在线，响应时间 < 2 秒

#### 1.1.3 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 超级管理员 | 系统最高权限管理者 | 所有功能权限 |
| 科室管理员 | 负责本科室物品管理 | 物品管理、库存管理、统计分析 |
| 普通用户 | 教师、后勤人员 | 库存查询、物品领用、盘点录入 |

### 1.2 功能需求（PRD）

#### 1.2.1 用户管理模块（M001）

**需求描述**：实现用户的登录、退出、信息维护、权限管理。

**功能清单**：

| 编号 | 功能名称 | 优先级 | 用户角色 | 说明 |
|------|---------|-------|---------|------|
| M001-01 | 用户登录 | P0 | 所有用户 | 用户名+密码登录，JWT Token 认证 |
| M001-02 | 用户退出 | P0 | 所有用户 | 清除 Session 和 Token |
| M001-03 | 修改密码 | P1 | 所有用户 | 验证原密码，设置新密码 |
| M001-04 | 用户信息维护 | P1 | 所有用户 | 修改个人信息（姓名、邮箱、手机） |
| M001-05 | 用户列表查询 | P1 | 超级管理员 | 查询所有用户信息 |
| M001-06 | 用户创建/编辑 | P2 | 超级管理员 | 创建用户、编辑用户信息、重置密码 |
| M001-07 | 用户删除/禁用 | P2 | 超级管理员 | 删除用户或禁用账号 |

**业务规则**：
- 密码必须加密存储（使用 bcrypt）
- Token 有效期 24 小时
- 同一用户只能在一个设备登录
- 超级管理员不能删除自己

**需求描述**：实现物品的分类管理、信息维护、批量导入导出。

| M003-03 | 库存盘点 | P1 | 所有用户 | 录入盘点数据，计算差异 |
| M003-04 | 库存查询 | P0 | 所有用户 | 查询物品实时库存 |
| M003-05 | 库存预警设置 | P1 | 科室管理员+ | 设置物品最小/最大库存 |

## 2. 第二阶段：脚手架搭建与代码架构

### 2.1 项目结构设计

#### 2.1.1 目录结构原则

- **分层清晰**：按职责划分目录（api、models、schemas、utils）
- **模块化**：每个功能模块独立成包

```python
"""
```

```python
数据库连接管理

功能说明：

- 会话管理：依赖注入获取会话
- 连接池：优化数据库连接性能
"""

from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker
from app.config import settings


# 创建数据库引擎（使用相对路径）

    settings.database_url,
    
    # SQLite 专用配置

        "check_same_thread": False,  # 允许多线程访问
        "check_integrity": True       # 检查完整性

# 创建会话工厂
SessionLocal = sessionmaker(
    autocommit=False,  # 不自动提交
    autoflush=False,   # 不自动刷新
    bind=engine
)

# 创建基础模型类（所有 SQLAlchemy 模型继承此类）
Base = declarative_base()


def get_db():
    """
    获取数据库会话（依赖注入）
    
    Yields:
        Session: 数据库会话实例
    
    使用方式：
        @app.get("/items")
        def read_items(db: Session = Depends(get_db)):
            items = db.query(Item).all()
            return items
    
    说明：
        - 使用依赖注入，FastAPI 自动管理会话生命周期
        - 请求开始时创建会话，请求结束后自动关闭
        - 确保每个请求使用独立的数据库会话
    """
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()


def init_db():

        - 根据定义的模型类创建数据库表

        - 建议在应用启动时调用

    Base.metadata.create_all(bind=engine)
```

```python
"""
CampusAssetManager/backend/app/models/base.py
基础模型类

功能说明：
- 定义所有模型的公共字段
- 提供通用方法（to_dict、__repr__）

设计原则：
- 面向对象：使用继承减少重复代码
- 声明式：通过类属性定义表结构
"""

from sqlalchemy import Column, Integer, DateTime, Text
from sqlalchemy.ext.declarative import declared_attr
from datetime import datetime
from app.utils.database import Base


class BaseModel(Base):
    """
    基础模型类
    
    所有模型类都应继承此类，自动获得公共字段和方法
    """
    
    __abstract__ = True  # 声明为抽象基类，不会创建表
    
    # 公共字段：主键
    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    
    # 公共字段：创建时间（自动设置为当前时间）
    create_time = Column(DateTime, default=datetime.now, nullable=False)
    
    # 公共字段：更新时间（更新时自动设置）
    update_time = Column(DateTime, default=datetime.now, onupdate=datetime.now, nullable=False)
    
    @declared_attr
    def __tablename__(cls):
        """
        自动生成表名
        
        Returns:
            str: 表名（类名转为小写并加下划线）
        
        示例：
            UserInfo -> user_info
            GoodsCategory -> goods_category
        """
        # 将类名转为小写，驼峰命名转为下划线命名
        name = cls.__name__[0].lower() + cls.__name__[1:]
        result = []
        for c in name:
            if c.isupper():
                result.append('_')
                result.append(c.lower())
            else:
                result.append(c)
        return ''.join(result)
    
    def to_dict(self):
        """
        将模型对象转为字典
        
        Returns:
            dict: 模型对象的字典表示
        
        使用场景：
            - 序列化为 JSON
            - 前端返回数据
        """
        return {
            column.name: getattr(self, column.name)
            for column in self.__table__.columns
        }
    
    def __repr__(self):
        """
        模型对象的字符串表示
        
        Returns:
            str: 模型对象的描述
        
        使用场景：
            - 调试输出
            - 日志记录
        """
        return f"<{self.__class__.__name__} id={self.id}>"
```

### 2.5 API 设计规范

#### 2.5.1 RESTful API 命名规范

本系统采用 RESTful 风格的 API 设计，所有接口遵循统一的命名标准。

**API 路由格式：**
```
/v{version}/{module}/{function}
```

**格式说明：**
- **v{version}**：版本号前缀，如 `v1`、`v2`。版本号用 `v` 开头加数字表示
- **{module}**：模块名称，使用小写英文单词，如 `auth`、`goods`、`stock`、`statistics`、`system`
- **{function}**：功能名称，使用小写英文单词，如 `login`、`list`、`create`、`update`、`delete`

**完整 URL 示例：**
- 登录接口：`http://127.0.0.1:5000/v1/auth/login`
- 物品列表：`http://127.0.0.1:5000/v1/goods/`
- 库存入库：`http://127.0.0.1:5000/v1/stock/in`
- 数据概览：`http://127.0.0.1:5000/v1/statistics/overview`
- 数据备份：`http://127.0.0.1:5000/v1/system/backup`

#### 2.5.2 HTTP 方法使用规范

遵循 RESTful 设计原则，根据操作类型选择合适的 HTTP 方法：

| HTTP 方法 | 操作类型 | 说明 | 示例 |
|-----------|---------|------|------|
| GET | 查询 | 获取资源，参数通过 URL 传递 | `GET /v1/goods/?page=1&page_size=20` |
| POST | 创建 | 创建新资源，参数通过 Request Body 传递 | `POST /v1/goods/` |
| PUT | 更新 | 完整更新资源，参数通过 Request Body 传递 | `PUT /v1/goods/1` |
| DELETE | 删除 | 删除资源，参数通过 URL 传递 | `DELETE /v1/goods/1` |

**使用原则：**
- GET 请求不允许修改服务器状态
- POST 用于创建非幂等操作
- PUT 用于幂等更新操作
- DELETE 用于删除操作

#### 2.5.3 版本管理策略

**版本号规则：**
- 主版本号：重大功能变更、API 不兼容升级（如 v1 → v2）
- 初始版本：v1
- 版本号仅用数字，不使用字母或特殊字符

**版本共存：**
- 不同版本的 API 可以共存，新版本发布后，旧版本保留至少一个维护周期
- 前端通过环境变量配置 API 版本号，便于统一切换
- 后端通过路由前缀区分版本，如 `app.include_router(auth.router, prefix="/v1/auth")`

**版本升级流程：**
1. 开发新版本 API（如 v2）
2. 前端逐步迁移到 v2
3. 旧版本 v1 进入维护期
4. 确认无客户端使用后，废弃 v1

#### 2.5.4 请求与响应规范

**请求规范：**

1. **请求头（Request Headers）：**
   ```http
   Content-Type: application/json
   ```

#### 3.2.1 安全认证模块（app/core/security.py）

```python
"""
CampusAssetManager/backend/app/core/security.py
安全认证模块

功能说明：
- 密码加密（使用 bcrypt）
- JWT Token 生成与验证
- 权限验证（基于角色的访问控制 RBAC）

设计原则：
- 声明式：使用 Pydantic 定义 Token 载荷
- 面向对象：封装认证逻辑为类
- 封装清晰：提供简洁的公共接口

依赖库：
- passlib: 密码加密
- PyJWT: Token 生成与验证
"""

from datetime import datetime, timedelta
from typing import Optional, Dict
from jose import JWTError, jwt
from passlib.context import CryptContext
from pydantic import BaseModel

from app.config import settings


# ==================== 密码管理 ====================

class PasswordManager:
    """
    密码管理器
    
    功能：
        - 密码加密（hash）
        - 密码验证（verify）
    
    使用方式：
        manager = PasswordManager()
        hashed = manager.hash("password123")
        is_valid = manager.verify("password123", hashed)
    """
    
    def __init__(self):
        """
        初始化密码管理器
        
        使用 bcrypt 算法，自动处理盐值
        """
        self.pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
    
    def hash(self, plain_password: str) -> str:
        """
        加密密码
        
        Args:
            plain_password: 明文密码
        
        Returns:
            str: 加密后的密码
        
        Examples:
            >>> manager = PasswordManager()
            >>> manager.hash("admin123")
            '$2b$12$EixZaYVK1fsbw1ZfbX3OXePaWxn96p36WQoeG6Lruj3vjPGga31lW'
        """
        return self.pwd_context.hash(plain_password)
    
    def verify(self, plain_password: str, hashed_password: str) -> bool:
        """
        验证密码
        
        Args:
            plain_password: 明文密码
            hashed_password: 加密后的密码
        
        Returns:
            bool: 验证结果
        
        Examples:
            >>> manager = PasswordManager()
            >>> manager.verify("admin123", "$2b$12$...")
            True
        """
        return self.pwd_context.verify(plain_password, hashed_password)


# ==================== Token 管理 ====================

class TokenPayload(BaseModel):
    """
    Token 载荷（声明式定义）
    
    Attributes:
        sub: 主题（用户名）
        role: 用户角色
        exp: 过期时间（自动添加）
        iat: 签发时间（自动添加）
    """
    sub: str  # subject（用户名）
    role: str  # 用户角色


class TokenManager:
    """
    Token 管理器
    
    功能：
        - 生成 Token（encode）
        - 验证 Token（decode）
        - 解析 Token 载荷
    
    使用方式：
        manager = TokenManager()
        token = manager.create({"sub": "admin", "role": "super_admin"})
        payload = manager.verify(token)
    """
    
    def __init__(self):
        """
        初始化 Token 管理器
        
        从配置中读取密钥和算法
        """
        self.secret_key = settings.secret_key
        self.algorithm = settings.algorithm
        self.expire_minutes = settings.access_token_expire_minutes
    
    def create(self, payload: TokenPayload, expires_delta: Optional[timedelta] = None) -> str:
        """
        生成 JWT Token
        
        Args:
            payload: Token 载荷
            expires_delta: 自定义过期时间（可选）
        
        Returns:
            str: JWT Token 字符串
        
        Examples:
            >>> manager = TokenManager()
            >>> token = manager.create(TokenPayload(sub="admin", role="super_admin"))
            'eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...'
        """
        # 计算过期时间
        if expires_delta:
            expire = datetime.utcnow() + expires_delta
        else:
            expire = datetime.utcnow() + timedelta(minutes=self.expire_minutes)
        
        # 添加过期时间到载荷
        to_encode = payload.dict()
        to_encode.update({"exp": expire})
        
        # 生成 Token
        encoded_jwt = jwt.encode(to_encode, self.secret_key, algorithm=self.algorithm)
        return encoded_jwt
    
    def verify(self, token: str) -> TokenPayload:
        """
        验证 JWT Token
        
        Args:
            token: JWT Token 字符串
        
        Returns:
            TokenPayload: Token 载荷
        
        Raises:
            JWTError: Token 验证失败
        
        Examples:
            >>> manager = TokenManager()
            >>> payload = manager.verify("eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...")
            >>> payload.sub
            'admin'
        """
        try:
            payload = jwt.decode(token, self.secret_key, algorithms=[self.algorithm])
            return TokenPayload(**payload)
        except JWTError as e:
            raise JWTError(f"Token 验证失败: {str(e)}")


# ==================== 权限管理 ====================

class RoleChecker:
    """
    角色权限检查器
    
    功能：
        - 检查用户是否具有指定角色
        - 检查用户是否具有任一角色（多角色）
    
    使用方式：
        checker = RoleChecker(["super_admin", "dept_admin"])
        await checker(current_user={"role": "super_admin"})
    """
    
    def __init__(self, allowed_roles: list):
        """
        初始化角色检查器
        
        Args:
            allowed_roles: 允许的角色列表
        
        Examples:
            >>> checker = RoleChecker(["super_admin", "dept_admin"])
        """
        self.allowed_roles = allowed_roles
    
    async def __call__(self, current_user: dict) -> dict:
        """
        检查用户权限
        
        Args:
            current_user: 当前用户信息（令牌载荷）
        
        Returns:
            dict: 当前用户信息（验证通过）
        
        Raises:
            HTTPException: 权限不足（403）
        
        Examples:
            >>> checker = RoleChecker(["super_admin"])
            >>> await checker({"role": "super_admin"})
            {'role': 'super_admin'}
        """
        from fastapi import HTTPException, status
        
        if current_user.get("role") not in self.allowed_roles:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"权限不足，需要以下角色之一：{', '.join(self.allowed_roles)}"
            )
        return current_user
```

### 3.2.2 用户服务模块（app/services/auth_service.py）

```python
"""
CampusAssetManager/backend/app/services/auth_service.py
认证服务模块

功能说明：
- 用户登录验证
- 用户注册
- 密码修改
- 用户信息查询

设计原则：
- 面向对象：使用 AuthService 类封装认证逻辑
- 声明式：使用 Pydantic 定义数据模型
- 封装清晰：提供简洁的公共方法

与其他模块交互：
- Repository 层：用户数据访问
- Security 层：密码加密、Token 生成
"""

from typing import Optional, Dict
from fastapi import HTTPException, status
from sqlalchemy.orm import Session

from app.core.security import PasswordManager, TokenManager, TokenPayload
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate, UserLogin, UserUpdate, UserResponse


class AuthService:
    """
    认证服务类
    
    处理认证相关的业务逻辑：
        - 用户登录
        - 用户注册
        - 密码修改
        - Token 生成与验证
    
    设计原则：
        - 单一职责：只处理认证逻辑
        - 依赖注入：通过构造函数注入依赖
        - 异常处理：统一的异常处理机制
    """
    
    def __init__(
        self,
        password_manager: PasswordManager = None,
        token_manager: TokenManager = None,
        user_repository: UserRepository = None
    ):
        """
        初始化认证服务（依赖注入）
        
        Args:
            password_manager: 密码管理器（可选，默认使用实例）
            token_manager: Token 管理器（可选，默认使用实例）
            user_repository: 用户数据访问层（可选，默认使用实例）
        
        设计说明：
            - 依赖注入便于测试
            - 提供默认实现，正常使用时无需手动注入
        """
        self.password_manager = password_manager or PasswordManager()
        self.token_manager = token_manager or TokenManager()
        self.user_repository = user_repository
    
    def login(
        self,
        login_data: UserLogin,
        db: Session
    ) -> Dict[str, str]:
        """
        用户登录
        
        功能说明：
            1. 根据用户名查询用户
            2. 验证密码
            3. 生成 JWT Token
            4. 返回 Token 信息
        
        Args:
            login_data (UserLogin): 登录数据
                - username: 用户名
                - password: 密码
            db (Session): 数据库会话
        
        Returns:
            dict: Token 信息
                - access_token: JWT Token
                - token_type: Token 类型（bearer）
        
        Raises:
            HTTPException: 
                - 401: 用户名或密码错误
                - 404: 用户不存在
        
        Examples:
            >>> service = AuthService()
            >>> result = service.login(
            ...     UserLogin(username="admin", password="admin123"),
            ...     db=db
            ... )
            >>> result["access_token"]
            'eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...'
        """
        # 1. 查询用户
        user = self.user_repository.get_by_username(login_data.username, db)
        if not user:
            raise HTTPException(
                status_code=status.HTTP_404_NOT_FOUND,
                detail="用户不存在"
            )
        
        # 2. 验证密码
        if not self.password_manager.verify(login_data.password, user.password):
            raise HTTPException(
                status_code=status.HTTP_401_UNAUTHORIZED,
                detail="用户名或密码错误"
            )
        
        # 3. 生成 Token
        payload = TokenPayload(sub=user.username, role=user.role)
        access_token = self.token_manager.create(payload)
        
        # 4. 返回 Token
        return {
            "access_token": access_token,
            "token_type": "bearer"
        }
    
    def register(
        self,
        user_data: UserCreate,
        db: Session
    ) -> UserResponse:
        """
        用户注册
        
        功能说明：
            1. 验证用户名唯一性
            2. 加密密码
            3. 创建用户
            4. 返回用户信息
        
        Args:
            user_data (UserCreate): 用户数据
            db (Session): 数据库会话
        
        Returns:
            UserResponse: 用户信息
        
        Raises:
            HTTPException: 
                - 400: 用户名已存在
        
        Examples:
            >>> service = AuthService()
            >>> result = service.register(
            ...     UserCreate(username="newuser", password="123456", real_name="新用户"),
            ...     db=db
            ... )
            >>> result.username
            'newuser'
        """
        # 1. 验证用户名唯一性
        existing_user = self.user_repository.get_by_username(user_data.username, db)
        if existing_user:
            raise HTTPException(
                status_code=status.HTTP_400_BAD_REQUEST,
                detail="用户名已存在"
            )
        
        # 2. 加密密码
        hashed_password = self.password_manager.hash(user_data.password)
        
        # 3. 创建用户
        user = self.user_repository.create(
            {
                **user_data.dict(),
                "password": hashed_password
            },
            db
        )
        
        # 4. 返回用户信息
        return UserResponse(
            code=200,
            message="注册成功",
            data=user
        )
    
    def change_password(
        self,
        old_password: str,
        new_password: str,
        current_user: Dict,
        db: Session
    ) -> Dict[str, str]:
        """
        修改密码
        
        功能说明：
            1. 验证原密码
            2. 加密新密码
            3. 更新数据库
        
        Args:
            old_password (str): 原密码
            new_password (str): 新密码
            current_user (dict): 当前用户信息
            db (Session): 数据库会话
        
        Returns:
            dict: 操作结果
        
        Raises:
            HTTPException: 
                - 400: 原密码错误
        
        Examples:
            >>> service = AuthService()
            >>> result = service.change_password(
            ...     "oldpass",
            ...     "newpass",
            ...     {"username": "admin"},
            ...     db=db
            ... )
            >>> result["message"]
            '密码修改成功'
        """
        # 1. 查询用户
        user = self.user_repository.get_by_username(current_user["sub"], db)
        if not user:
            raise HTTPException(
                status_code=status.HTTP_404_NOT_FOUND,
                detail="用户不存在"
            )
        
        # 2. 验证原密码
        if not self.password_manager.verify(old_password, user.password):
            raise HTTPException(
                status_code=status.HTTP_400_BAD_REQUEST,
                detail="原密码错误"
            )
        
        # 3. 加密新密码
        hashed_password = self.password_manager.hash(new_password)
        
        # 4. 更新密码
        self.user_repository.update(user.user_id, {"password": hashed_password}, db)
        
        return {"message": "密码修改成功"}
```

由于篇幅限制，其他模块的实现将在第四阶段详细描述。此处仅展示核心模块的设计规范和编码标准。

```python
"""
CampusAssetManager/backend/scripts/deploy.py
一键部署脚本

功能说明：
- 备份数据库
- 安装依赖
- 运行迁移
- 启动服务
- 健康检查

使用方式：
    python scripts/deploy.py
"""

import os
import sys
import subprocess
import shutil
from datetime import datetime


def backup_database():
    """
    备份数据库
    
    Returns:
        str: 备份文件路径
    """
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    backup_dir = "./backup/backups"
    os.makedirs(backup_dir, exist_ok=True)
    
    source_path = "./db/campus_asset.db"
    backup_path = f"{backup_dir}/campus_asset_{timestamp}.db"
    
    shutil.copy2(source_path, backup_path)
    print(f"数据库备份成功: {backup_path}")
    
    return backup_path


def install_dependencies():
    """安装依赖"""
    print("正在安装依赖...")
    subprocess.run(["pip", "install", "-r", "requirements.txt"], check=True)
    print("依赖安装完成")


def run_migrations():
    """运行数据库迁移"""
    print("正在运行数据库迁移...")
    from app.utils.database import init_db
    init_db()
    print("数据库迁移完成")


def start_service():
    """启动服务"""
    print("正在启动服务...")
    subprocess.Popen([
        "uvicorn",
        "app.main:app",
        "--host", "0.0.0.0",
        "--port", "5000",
        "--workers", "4"
    ])
    print("服务启动完成")


def health_check():
    """健康检查"""
    import requests
    print("正在执行健康检查...")
    
    max_retries = 10
    for i in range(max_retries):
        try:
            response = requests.get("http://127.0.0.1:5000/health", timeout=5)
            if response.status_code == 200:
                print("健康检查通过")
                return True
        except Exception as e:
            print(f"健康检查失败（第 {i+1} 次）: {str(e)}")
            import time
            time.sleep(2)
    
    raise Exception("健康检查失败")


def deploy():
    """
    执行部署流程
    
    步骤：
        1. 备份数据库
        2. 安装依赖
        3. 运行迁移
        4. 启动服务
        5. 健康检查
    """
    try:
        # 1. 备份数据库
        backup_path = backup_database()
        
        # 2. 安装依赖
        install_dependencies()
        
        # 3. 运行迁移
        run_migrations()
        
        # 4. 启动服务
        start_service()
        
        # 5. 健康检查
        health_check()
        
        print("========================================")
        print("部署成功！")
        print(f"数据库备份: {backup_path}")
        print("服务地址: http://127.0.0.1:5000")
        print("API 文档: http://127.0.0.1:5000/docs")
        print("========================================")
        
    except Exception as e:
        print(f"部署失败: {str(e)}")
        sys.exit(1)


if __name__ == "__main__":
    deploy()
```

```python
"""
CampusAssetManager/backend/utils/logger.py
日志工具

功能说明：
- 配置日志格式
- 日志级别管理
- 日志文件轮转
"""

import logging
from logging.handlers import RotatingFileHandler
from app.config import settings


def setup_logger():
    """
    配置日志 logger
    
    日志格式：
        [时间] [级别] [模块] 信息
    
    日志文件：
        - app.log: 应用日志
        - app.log.1, app.log.2: 历史日志（轮转）
    """
    logger = logging.getLogger()
    logger.setLevel(getattr(logging, settings.log_level))
    
    # 创建文件处理器（支持轮转）
    file_handler = RotatingFileHandler(
        settings.log_file,
        maxBytes=10 * 1024 * 1024,  # 10MB
        backupCount=5  # 保留 5 个日志文件
    )
    
    # 创建控制台处理器
    console_handler = logging.StreamHandler()
    
    # 日志格式
    formatter = logging.Formatter(
        '[%(asctime)s] [%(levelname)s] [%(name)s] %(message)s',
        datefmt='%Y-%m-%d %H:%M:%S'
    )
    
    file_handler.setFormatter(formatter)
    console_handler.setFormatter(formatter)
    
    logger.addHandler(file_handler)
    logger.addHandler(console_handler)
    
    return logger


# 初始化日志
logger = setup_logger()
```
